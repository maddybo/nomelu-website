Getting started

On first launch, choose a display name and a theme. Create a notebook by choosing a name and a location in Files, or select an existing folder.

Use the notebook controls to create or open another notebook. On Mac and Linux, you can also open standalone Markdown files and save back to the original file.

Keeping notes and tasks together

Detailed tasks, history and attachments live alongside notes in the notebook’s hidden .nomelu folder. Move or back up the complete notebook to keep those details. Exporting an individual Markdown note does not include all separate task files.

Notifications and background refresh

Enable deadline notifications in Settings and allow notifications when iOS asks. Check Focus and system notification settings if reminders are quiet.

iOS decides when background refresh runs. Pull down in Notes or Tasks, or reopen Nomelu, to refresh your open sources.

Files and synchronization

Local notebooks work without an account. For Nomelu synchronization and sharing, sign in through Settings → Synchronization, then explicitly connect a notebook. Its notes, tasks and attachments are sent to the Nomelu service; unconnected local notebooks stay local. Check the document status for queued changes, confirmed synchronization or errors.

iCloud Drive and other file providers can also synchronize folders separately under their own policies. If a file changes elsewhere, Nomelu can merge independent edits or let you compare overlapping changes.

Documents and shared content

Create a New document and choose Note or Tasks List. On iPhone/iPad the choice appears between the document name and location. Notes support writing, images, links and tasks; Tasks List provides a focused checklist.

On iPhone/iPad, use the system share sheet to send text, links, images or files to Nomelu. Choose an existing note, a task or a new note, then open Nomelu to complete the import. Unavailable destinations remain in the private inbox for retry.

Deleting a synchronization account

Open Settings → Danger zone → Delete sync account and server data. This deletes your account and server notebooks you own while keeping your local files. Signing out alone does not delete the account. See the privacy policy for shared-copy behavior and contact us if you need help.
